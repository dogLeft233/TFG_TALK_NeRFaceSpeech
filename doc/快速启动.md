# 快速启动指南

## 环境安装

### 安装 llm_talk 环境

```bash
conda env create -f environment/llm_talk.yaml --prefix environment/llm_talk
```

安装完成后，激活环境：
```bash
conda activate environment/llm_talk
```

### 安装 nerffacespeech 环境

```bash
conda env create -f environment/nerffacespeech.yaml --prefix environment/nerffacespeech
```

安装完成后，激活环境：
```bash
conda activate environment/nerffacespeech
```

安装`nvdiffrast`依赖:
```bash
cd NeRFFaceSpeech_Code/Deep3DFaceRecon_pytorch
git clone https://github.com/NVlabs/nvdiffrast
cd nvdiffrast
pip install .
```
