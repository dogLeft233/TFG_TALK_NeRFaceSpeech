在 conda 里，**把环境安装到“指定路径”**是一个**标准功能**，不是 hack。核心就是用 **`--prefix`（或 `-p`）**，而不是 `-n`。

下面我按 **创建 / 安装 / 使用 / 迁移** 给你一次讲清楚。

---

## 一、创建环境到指定路径（最常用）

```bash
conda create -p /path/to/env python=3.10
```

例如：

```bash
conda create -p /mnt/data/envs/torch python=3.10
```

📌 说明

* `/path/to/env` 是**环境目录**
* 不需要出现在 `conda env list`
* **可以不在 conda 安装目录下**

---

## 二、向指定路径的环境安装包

### 方法 1：激活后安装（推荐）

```bash
conda activate /mnt/data/envs/torch
conda install numpy pytorch
```

### 方法 2：不激活，直接指定路径

```bash
conda install -p /mnt/data/envs/torch numpy pytorch
```

---

## 三、使用指定路径的环境

### 1️⃣ 激活（推荐）

```bash
conda activate /mnt/data/envs/torch
```

### 2️⃣ 不激活，直接用

```bash
/mnt/data/envs/torch/bin/python your_script.py
```

---

## 四、查看 / 管理路径环境

### 查看所有环境（含路径）

```bash
conda env list
```

你会看到类似：

```
/mnt/data/envs/torch
```

---

### 删除指定路径环境

```bash
conda remove -p /mnt/data/envs/torch --all
```

---

## 五、典型使用场景（你很可能正需要）

### ✅ 场景 1：空间不够（HOME 爆了）

```bash
conda create -p /data/envs/myenv python=3.8
```

---

### ✅ 场景 2：项目自带环境（可打包/迁移）

```bash
project/
├── env/
│   └── bin/python
├── train.py
```

```bash
conda create -p ./env python=3.10
```

---

### ✅ 场景 3：配合 conda-pack（强烈推荐）

```bash
conda create -p /mnt/envs/myenv python=3.10
conda activate /mnt/envs/myenv
# 安装依赖
conda-pack -p /mnt/envs/myenv -o myenv.tar
```

---

## 六、常见坑（一定要避开）

### ❌ 1. 不要混用 `-n` 和 `-p`

❌ 错误：

```bash
conda create -n myenv -p /path/env
```

✔ 正确：二选一

---

### ❌ 2. 环境路径不能有空格

```bash
/path/with space/env   ❌
```

---

### ❌ 3. pip 一定要对准环境

```bash
which pip
which python
```

应指向：

```
/path/to/env/bin/
```

---

## 七、一句话总结（记住这个）

> **conda 装到指定路径 = 用 `-p / --prefix`**
