# 一、先给结论（你可以直接照做）

## ✅「完美 requirements」的黄金法则

> **requirements.txt 只负责 pip 的“纯 Python 世界”
> PyTorch / CUDA / 编译型包，永远不要混进去**

---

# 二、为什么你之前的方法“必然翻车”

### ❌ `pip freeze > requirements.txt` 的三个原罪

1. **把 conda 的东西冻进 pip**

   ```txt
   six @ file:///tmp/build/...
   ```

   → 别的机器不存在

2. **把 PyTorch 内部依赖显式写出**

   ```txt
   nvidia-cudnn-cu12
   ```

   → CUDA 版本稍微一变就炸

3. **不区分安装顺序**

   * torch
   * pytorch3d
   * nvdiffrast
     → 顺序错 100% 失败

所以：

> ❌ `pip freeze` **不能直接用来“交付环境”**

# 三、工业级「完美 requirements」生成流程（强烈推荐）

下面这套流程，我会给你 **WHY + HOW + 示例**。

---

## 🧱 Step 0：认清职责边界（非常重要）

| 层级         | 工具     | 管什么                 |
| ---------- | ------ | ------------------- |
| OS / CUDA  | Docker | 驱动 / libc / nvcc    |
| Python 运行时 | conda  | python / pip        |
| DL 框架      | pip    | torch / torchvision |
| 项目依赖       | pip    | diffusers / librosa |

👉 **不要跨层管理**

---

## 🧩 Step 1：最小 conda 环境（永远只干一件事）

```bash
conda create -n nerffacespeech python=3.9 pip
```

导出：

```bash
conda env export --from-history \
  | grep -v "^prefix:" \
  > environment.min.yaml
```

结果应该 **极短**：

```yaml
name: nerffacespeech
channels:
  - conda-forge
dependencies:
  - python=3.9
  - pip
```

✔ 稳定
✔ solver 不炸
✔ Docker 友好

---

## 🔥 Step 2：**手工安装 PyTorch（永远手工）**

```bash
pip install torch==2.1.2+cu118 \
    torchvision==0.16.2+cu118 \
    torchaudio==2.1.2+cu118 \
    --index-url https://download.pytorch.org/whl/cu118
```

👉 **不要把 torch 写进 requirements**

---

## 🧱 Step 3：手工安装「强耦合框架」

例如：

```bash
pip install pytorch3d==0.7.8 \
  -f https://dl.fbaipublicfiles.com/pytorch3d/packaging/wheels/py39_cu118_pyt212/download.html
```

再比如：

```bash
pip install git+https://github.com/NVlabs/nvdiffrast.git@<commit>
```

👉 这些 **永远单独装**

---

## 🧼 Step 4：生成「干净的 requirements」

### 正确命令（不是 pip freeze）

```bash
pip list --format=freeze \
 | grep -v torch \
 | grep -v torchvision \
 | grep -v torchaudio \
 | grep -v pytorch3d \
 | grep -v nvidia- \
 | grep -v "@ file://" \
 > requirements.txt
```

这个 requirements 应该满足：

* ✅ 全是 `包名==版本`
* ❌ 没有本地路径
* ❌ 没有 CUDA runtime
* ❌ 没有 torch 家族

---

## 🧠 Step 5：人为审查（不可省略）

你要 **人工扫一遍**：

### 必删项

* `@ file:///`
* `@ git+`（移到单独文件）
* `nvidia-*`
* `mkl-*`（如果是 conda 的）

### 必确认项

* numpy / scipy / numba 的版本兼容性
* transformers / diffusers 是否锁版本

```text
environment.min.yaml

```

### `requirements.torch.txt`

```txt
torch==2.1.2+cu118

torchaudio==2.1.2+cu118
```

# 五、Docker 中「零翻车」安装顺序

```dockerfile
# conda env
RUN conda env create -f environment.min.yaml -p /opt/env
ENV PATH=/opt/env/bin:$PATH

# torch
RUN pip install -r requirements.torch.txt \
  --index-url https://download.pytorch.org/whl/cu118

# pytorch3d
RUN pip install -r requirements.pytorch3d.txt

# project deps
RUN pip install -r requirements.txt
```

**一次成功，不改一行**

👉 那它就是「完美 requirements」。
