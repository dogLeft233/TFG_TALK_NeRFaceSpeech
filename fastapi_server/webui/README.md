## 概述

NeRFFaceSpeech Web UI 是一个基于 HTML/CSS/JavaScript 的前端界面，提供了完整的开发者模式体验。

### 核心功能模块

1. **视频生成** - 文本输入 → LLM+TTS → NeRF 视频生成
2. **人机对话** - 实时对话，支持 LLM 问答和 TTS 语音回复
3. **模型训练** - StyleNeRF 模型微调训练（包含完整的训练配置、监控和管理功能）

### 开发者工具

4. **后端显示屏** - 实时查看后端输出、日志和调试信息

所有功能都通过 FastAPI 后端接口实现，前端负责用户交互和界面展示。

## 快速开始

### 🚀 一键启动（推荐）

使用一键启动脚本，自动设置环境变量、启动服务器并打开浏览器：

```bash
cd fastapi_server
python start.py
```

启动脚本会自动：
1. 设置必要的环境变量（PIP_INDEX_URL、TORCH_HOME、HF_ENDPOINT、HF_HOME）
2. 启动后端服务器（FastAPI，端口 8000）
3. 启动前端服务器（HTTP，端口 7860）
4. 打开浏览器显示选择页面

然后你可以选择：
- **后端显示屏** - 查看后端日志和调试信息
- **前端应用** - 使用三个核心功能模块

### 手动启动（高级用户）

#### 1. 设置环境变量

```bash
export PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
export TORCH_HOME=/root/autodl-tmp/weights
export HF_ENDPOINT=https://hf-mirror.com
export HF_HOME=/root/autodl-tmp/Hugging_Face
```

#### 2. 启动后端服务器

```bash
cd fastapi_server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

后端地址：`http://localhost:8000/`
- 根路径显示：**后端显示屏**（logs.html）
- API 文档：`http://localhost:8000/docs`

#### 3. 启动前端服务器

```bash
cd fastapi_server
python simple_web.py
```

前端地址：`http://localhost:7860/`
- 根路径显示：**选择页面**（start.html）
- 前端主页：`http://localhost:7860/index.html`

### 推荐配置

- 屏幕分辨率：1920x1080 或更高（已优化响应式布局）
- 浏览器：Chrome、Edge、Firefox（最新版本）
- 网络：确保能访问 `http://localhost:8000`（后端 API）

### 🎬 视频生成页面 (`generate.html`)

**功能**：从文本生成 NeRF 视频

**操作流程**：

1. **输入文本**
   - 在文本框中输入要说的话
   - 例如："你好，请简要介绍一下人工智能"

2. **选择角色**
   - 从下拉菜单选择角色：`ayanami` 或 `Aerith`

3. **选择模型**
   - 点击"刷新模型列表"加载可用模型
   - 从下拉菜单选择 `.pkl` 模型文件

4. **生成视频**
   - 点击"🚀 开始生成视频"按钮
   - 等待生成完成（通常需要几分钟）
   - 视频会在右侧自动播放

**界面元素**：
- **左侧**：输入区域和配置选项
- **右侧**：视频播放区域
- **进度显示**：实时进度条（LLM → TTS → NeRF）、当前步骤提示、预计剩余时间
- **历史记录**：最近生成的视频列表（缩略图 + 时间戳），可点击重播
- **视频操作**：下载、全屏、播放速度控制、视频信息显示
- **参数显示**：显示当前使用的模型、角色、生成时间等参数

**注意事项**：
- 视频生成需要较长时间（通常5-10分钟），请耐心等待
- 生成过程中可以点击"取消生成"按钮中止
- 如果生成失败，查看状态日志中的错误信息
- 生成的视频会自动保存到服务器，可在历史记录中查看
- 支持视频下载、全屏播放和播放速度调节

### 💬 人机对话页面 (`chat.html`)

**功能**：与 AI 进行实时对话，支持文本和语音

**操作流程**：

#### 文本对话

1. **输入消息**
   - 在底部输入框输入问题
   - 按 `Enter` 发送，`Shift+Enter` 换行

2. **查看回复**
   - AI 回复会逐字显示（流式输出）
   - 自动播放语音回复（可关闭）

3. **音量控制**
   - 使用音量滑块调整音量（0-100%）
   - 点击 🔊/🔇 按钮静音/取消静音

#### 语音输入（待实现）

- 🎤 按钮：录制语音（需要语音识别 API 支持）
- 📁 按钮：上传音频文件（需要语音识别 API 支持）

#### 对话管理

点击左上角"💬 对话管理"打开侧边栏：

- **新建对话**：创建新的对话会话
- **对话历史**：查看和切换历史对话
- **编辑名称**：双击对话名称或点击 ✏️ 图标编辑
- **导出对话**：导出当前对话记录为文本文件
- **清空对话**：清空当前对话的所有消息

**界面特性**：
- 用户消息：右侧蓝色气泡
- AI 消息：左侧半透明气泡
- 消息状态：发送中 ⏳、已送达 ✓、错误 ❌
- 流式输出：AI 回复逐字显示
- 错误重试：失败消息可点击"🔄 重试"按钮

**快捷键**：
- `Enter`：发送消息
- `Shift+Enter`：换行
- `Esc`：关闭侧边栏

### 🎓 模型训练页面 (`train.html`)

**功能**：StyleNeRF 模型微调训练（完整功能版）

#### 训练配置

1. **训练数据上传**
   - 支持文件选择器或拖拽上传（浏览器限制，实际需手动输入路径）
   - 或直接输入训练数据目录路径
   - 例如：`/root/autodl-tmp/StyleNeRF/single_image_dataset`

2. **训练参数表单**
   - **学习率 (Learning Rate)**：默认 0.002
   - **批量大小 (Batch Size)**：默认 4
   - **训练轮数 (kimg)**：建议 50 左右（默认：50）
   - **快照间隔 (snap)**：模型保存间隔（默认：5）
   - **图像快照间隔 (imgsnap)**：图像保存间隔（默认：1）
   - **数据增强 (aug)**：选择 `noaug` 或 `crop`
   - **镜像翻转**：选择是否启用
   - **基础模型**：选择基础模型文件（从下拉菜单）
   - **模型配置**：选择模型配置（默认：`style_ffhq_ae_basic`）

3. **配置预设**
   - **保存配置**：点击"💾 保存配置"按钮，输入配置名称保存当前参数
   - **加载配置**：点击"📂 加载配置"按钮，选择已保存的配置快速应用

#### 训练监控

- **实时训练日志**：自动滚动显示训练输出，支持清空日志
- **训练进度条**：显示整体训练进度（0-100%）
- **Epoch/Step 显示**：实时显示当前训练轮数和步数
- **损失曲线图**：使用 Chart.js 可视化训练损失（Total Loss、G Loss、D Loss）
- **GPU 使用率显示**：显示 GPU 使用率、显存占用、温度等信息（需要后端 API 支持）
- **训练时间统计**：显示已用时间、预计剩余时间

#### 训练管理

- **训练任务列表**：显示所有训练任务（进行中/已完成/失败），可点击查看详情
- **暂停/恢复训练**：训练过程中可以暂停和恢复（需要后端 API 支持）
- **停止训练**：点击"停止训练"按钮（需要确认）
- **训练历史记录**：查看所有训练任务的历史记录

#### 模型管理

- **已训练模型列表**：显示所有已训练的模型（需要后端 API 支持）
- **模型预览**：生成测试视频预览模型效果
- **模型下载**：下载训练好的模型文件
- **模型删除**：删除不需要的模型
- **模型重命名**：重命名模型便于管理

**训练状态**：
- **运行中**：训练正在进行
- **已完成**：训练成功完成
- **失败**：训练过程中出错
- **已停止**：用户手动停止

**注意事项**：
- 训练数据需要是单张图像数据集目录
- 图像要求：1024x1024 像素，瞳孔位置需符合规范
- 训练时间较长，建议在 GPU 充足的服务器上运行
- 训练过程中可以随时查看日志、进度和损失曲线
- 配置预设功能便于快速应用常用训练参数

## 常见问题

### Q1: 页面无法加载或显示空白？

**解决方案**：
1. 确保后端服务器已启动（`http://localhost:8000`）
2. 检查浏览器控制台是否有错误信息
3. 尝试使用本地 HTTP 服务器而不是直接打开文件
4. 检查 CORS 配置是否正确

### Q2: 视频生成失败？

**可能原因**：
- 后端服务未启动
- 模型文件不存在
- 角色音频提示文件缺失
- 服务器资源不足

**解决方案**：
1. 查看状态日志中的具体错误信息
2. 确认后端服务正常运行
3. 检查模型文件路径是否正确
4. 确认服务器有足够的 GPU/内存资源

### Q3: 对话功能无响应？

**可能原因**：
- LLM API Key 未配置
- TTS 模型未加载
- 网络连接问题

**解决方案**：
1. 检查后端日志确认 LLM 和 TTS 模块是否正常
2. 确认 API Key 已正确配置
3. 查看浏览器控制台的网络请求状态

### Q4: 训练任务无法启动？

**可能原因**：
- 训练数据路径不存在
- 基础模型文件不存在
- 训练脚本路径错误

**解决方案**：
1. 确认训练数据路径正确且可访问
2. 确认基础模型文件存在于 `pretrained_networks` 目录
3. 检查后端日志查看详细错误信息

### Q5: 训练日志不更新？

**解决方案**：
1. 点击"刷新任务列表"手动刷新
2. 检查任务状态是否为"运行中"
3. 查看后端日志确认训练进程是否正常

### Q6: 如何修改 API 地址？

**解决方案**：
在每个 HTML 文件中找到：
```javascript
const FASTAPI_URL = "http://localhost:8000";
```
修改为你的后端服务器地址即可。

## 技术说明

### 文件结构

```
fastapi_server/
├── start.py              # 一键启动脚本（开发者模式）
├── simple_web.py         # 前端 HTTP 服务器
├── main.py               # FastAPI 后端服务器
├── config.py             # 配置文件
├── utils/                # 工具模块
│   ├── run_llm_talk.py   # LLM 和 TTS 调用
│   ├── run_nerffacespeech.py  # NeRF 视频生成
│   ├── run_chat.py       # 聊天对话
│   ├── run_training.py   # 训练任务管理
│   └── llm_talk_api_bridge.py  # LLM API 桥接
└── webui/                # 前端页面
    ├── start.html        # 选择页面（开发者入口）
    ├── index.html        # 前端主页（模块选择）
    ├── generate.html     # 视频生成页面
    ├── chat.html         # 人机对话页面
    ├── train.html        # 模型训练页面
    ├── logs.html         # 后端显示屏（摘要）
    ├── logs-full.html    # 后端显示屏（完整输出）
    ├── app.js            # 共享 JavaScript（如需要）
    ├── style.css         # 共享样式（如需要）
    └── README.md         # 本文档
```

### 后端 API 接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/` | GET | 后端显示屏（logs.html） |
| `/models` | GET | 获取模型列表 |
| `/generate_video` | POST | 生成视频 |
| `/chat` | POST | 完整对话（LLM + TTS） |
| `/llm_only` | POST | 纯 LLM 问答 |
| `/train/start` | POST | 启动训练 |
| `/train/status/{task_id}` | GET | 获取训练状态 |
| `/train/tasks` | GET | 列出所有训练任务 |
| `/train/stop/{task_id}` | POST | 停止训练 |
| `/logs` | GET | 获取日志输出（限制数量） |
| `/logs/full` | GET | 获取完整日志输出 |

### 数据存储

- **主题和字体设置**：保存在浏览器 `localStorage`（键名：`nerf_theme`、`nerf_font`、`nerf_font_size`）
- **对话历史**：保存在浏览器 `localStorage`
- **训练配置预设**：保存在浏览器 `localStorage`（键名：`train_configs`）
- **训练任务**：保存在后端服务器内存中（重启后清空）
- **日志缓冲**：保存在后端服务器内存中（最多 10000 条，重启后清空）

- ✅ Chrome/Edge（推荐）

- ✅ 一键启动脚本（`start.py`）- 自动设置环境变量、启动服务器、打开浏览器
- ✅ 选择页面（`start.html`）- 开发者模式入口，选择后端或前端
- ✅ 后端显示屏（`logs.html` 和 `logs-full.html`）- 实时查看后端输出和日志
- ✅ 训练页面全面优化 - 配置预设、GPU监控、损失曲线、模型管理等功能
- ✅ 视频生成页面优化 - 进度显示、历史记录、视频操作、错误处理

- ✅ 完整的三个功能模块（视频生成、对话、训练）
- ✅ 对话管理和历史记录
- ✅ 训练任务实时监控
- ✅ 响应式布局和优化
