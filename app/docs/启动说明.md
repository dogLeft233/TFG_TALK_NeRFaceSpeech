# 一键启动脚本使用说明

## 快速开始

### 方式一：使用 Bash 脚本（推荐）

```bash
cd app
./start.sh
```

或者：

```bash
cd app
bash start.sh
```

### 方式二：使用 Python 脚本

```bash
cd app
python start.py
```

或者：

```bash
cd app
./start.py
```

## 功能说明

启动脚本会自动：

1. ✅ 检查 conda 环境 `api` 是否存在
2. ✅ 激活 conda 环境 `api`
3. ✅ 进入 `app` 目录
4. ✅ 检查端口是否被占用（后端 8000，前端 7860）
5. ✅ 在后台启动后端服务（uvicorn）
6. ✅ 在前台启动前端服务（simple_web.py）

## 访问地址

启动成功后，可以通过以下地址访问：

- **前端主页**: http://localhost:7860/
- **后端 API**: http://localhost:8000/
- **API 文档**: http://localhost:8000/docs

## 停止服务

按 `Ctrl+C` 即可停止所有服务。脚本会自动清理后台进程。

## 查看日志

- 后端日志：`app/.backend.log`
- 前端日志：直接在终端显示

## 注意事项

1. 确保已安装 conda 并创建了 `api` 环境
2. 如果端口被占用，脚本会提示是否继续
3. 如果启动失败，请查看日志文件获取详细错误信息

## 故障排除

### 问题：conda 环境不存在

**解决方案**：
```bash
conda env create -f ../environment/api.yaml
```

### 问题：端口被占用

**解决方案**：
1. 查找占用端口的进程：`lsof -i :8000` 或 `lsof -i :7860`
2. 停止占用端口的进程
3. 或者修改脚本中的端口配置

### 问题：后端启动失败

**解决方案**：
1. 查看后端日志：`cat app/.backend.log`
2. 检查依赖是否安装完整
3. 确认 `backend/main.py` 文件存在
