# 测试程序说明

## 视频生成功能测试

### 测试程序：`test_video_generation.py`

这个测试程序会：
1. 自动启动后端服务（FastAPI）
2. 等待后端服务就绪
3. 获取可用的模型和角色列表
4. 提交一个视频生成任务
5. 轮询任务状态直到完成
6. 验证生成的视频文件是否存在
7. 测试完成后自动停止后端服务

### 使用方法

```bash
cd gradio_app
python test/test_video_generation.py
```

### 测试配置

可以在脚本中修改以下配置：

- `API_BASE_URL`: 后端 API 地址（默认: `http://localhost:8000`）
- `BACKEND_STARTUP_TIMEOUT`: 后端启动超时时间（默认: 30 秒）
- `POLL_INTERVAL`: 状态轮询间隔（默认: 2 秒）
- `MAX_WAIT_TIME`: 最大等待时间（默认: 600 秒，10 分钟）
- `test_text`: 测试文本（默认: "你好，这是一个测试视频。"）

### 测试输出

测试程序会显示：
- 后端服务启动日志
- 系统信息（模型和角色列表）
- 任务提交结果
- 任务状态更新（实时）
- 视频文件验证结果
- 测试总结

### 注意事项

1. **确保端口 8000 未被占用**：测试程序会在 8000 端口启动后端服务
2. **确保 Conda 环境配置正确**：需要 `API_CONDA_PYTHON` 指向正确的 Python 解释器
3. **测试时间较长**：视频生成可能需要几分钟到十几分钟，请耐心等待
4. **自动清理**：测试完成后会自动停止后端服务，按 Ctrl+C 也可以中断测试

### 测试结果

- ✅ **成功**：返回码 0，视频文件已生成
- ❌ **失败**：返回码 1，查看输出了解失败原因
